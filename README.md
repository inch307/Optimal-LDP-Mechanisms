# Certifiably Optimal Mechanisms for Numerical Data under Local Differential Privacy

This repository accompanies the paper. It reproduces Figure 2 and Tables 2–11, including the expected mean squared errors on Adult, Credit, Beijing Housing, and Online News Popularity.

## Reproduce the results

Use Python 3.11 or newer.

```bash
python -m pip install -r requirements.txt
python reproduce.py
```

The script writes the tables, an MSE CSV, and the figure to `outputs/`. The saved mechanism inputs and normalized per-column value counts are in `data/`, along with the [column names, normalization ranges, and source file hashes](data/datasets.json). The script evaluates expectations directly.

## Verify or construct a mechanism

```bash
python -m pip install -r requirements-solver.txt
python design.py verify-lower --objective avg --eps 3
python design.py avg --prior adult --eps 3 --m 65 --out outputs/adult-eps3
```

Run `python design.py verify-lower` to check all included dual certificates. `python run_worst.py run --help` gives the options for the worst-case solver. The `aaa` and `n-output` subcommands of `design.py` construct AAA and finite-output candidates.

Table reproduction uses the selected designs and saved bounds. A fresh optimization can take much longer, especially on large grids, and can return a different feasible candidate. The full rational upper certificates are generated by the solvers.

Four percentage cells in Tables 2 and 5 differ from the PDF by 0.01 percentage points when rounded directly from the recomputed values.
